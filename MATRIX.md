All numbers come from the CLI levers (`pipeline reset / run / status`) on a clean database: Postgres 16 with `timezone = Asia/Jerusalem`, as in `docker-compose.yml`. The pipeline is deterministic, so every sequence repeats exactly. Raw-file counts were computed independently of the pipeline, straight from `raw/*.ndjson`.

## The tests (`tests/test_contract.py`, `make test`)

- **All six are red on this pipeline.** I also ran them against a privately patched pipeline, which is not submitted per the brief, and all six were green there.
- **No test hard-codes a row count.** Expected values come from the raw NDJSON, read by an independent parser inside the test, or from a second run of the pipeline (differential testing).
- **Invariant tests (hold on any dataset):** G4/G6 checks `findings.first/last_seen_at = min/max(sightings.detected_at)`. The second G3 test checks one findings row per case-insensitive identity.
- **API test:** the G5 test reads `/api/rollup` and `/api/summary`. It skips with a clear message if `make api` isn't running.
